# Developer Guide for Zenoh

## The Zenoh Family

### The Core Library

Zenoh has two major implementations. One is the **Zenoh** written in
Rust and the other is **Zenoh-Pico**, a native C re-implementation for
constrained devices.

The **Zenoh** library is feature-complete, bleeding-edge and uses the
fancy safe Rust programming language. It provides every necessary to
setup a Zenoh service, including the user API, routing and I/O
implementations. It is recommended for those working on algorithm
developement and research.

https://github.com/eclipse-zenoh/zenoh


**Zenoh Pico**, on the other hand, focuses on resource constrained
devices. It is written in pure C to ensure its compatibility with
embedded devices. It features low memory footprint and and lower CPU
usage, but lacks some of the features compared to the Zenoh library.

https://github.com/eclipse-zenoh/zenoh-pico

### Language Bindings

- C https://github.com/eclipse-zenoh/zenoh-c
